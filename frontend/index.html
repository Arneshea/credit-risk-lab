EVOLUTIONARY ALGORITHM

A genetic algorithm evolves fuzzy rule antecedents and Gaussian membership sets, balancing testable discrimination with rule compactness.

⌘
NEURAL LEARNING

Backpropagation adjusts membership centers, widths, and Sugeno rule outputs. A separate MLP is shown as a neural-network baseline.
